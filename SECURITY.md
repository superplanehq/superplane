# Security policy

This policy covers SuperPlane in the `superplanehq/superplane` repository.
The policy includes the enterprise directory in this repository.

## Report a vulnerability

Report a suspected vulnerability through GitHub private vulnerability reporting.
Use this page:

https://github.com/superplanehq/superplane/security/advisories/new

This is the only intake path for a security report.

Do not open a public issue for a suspected vulnerability.
Do not open a pull request for a suspected vulnerability.
Do not send a Discord message for a suspected vulnerability.

Include these details in the report:

- The affected area
- The version or commit
- The steps to reproduce the issue
- The impact
- Whether you can share a fix

Maintainers acknowledge the report on the advisory thread.
Maintainers keep the reporter updated on that thread.

## Fixes

Security fixes land on the default branch.

## Out of scope

Third-party service outages are out of scope.
Ordinary product bugs are out of scope.

Report an ordinary product bug in the [issue tracker](https://github.com/superplanehq/superplane/issues).
