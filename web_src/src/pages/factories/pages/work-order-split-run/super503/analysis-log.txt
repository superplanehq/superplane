The first screenshot shows:I see the issue clearly now. The DictateButton component is using a flex row layout that puts the transcript and button side by side, so as the transcript text grows (especially when it wraps to multiple lines), the button slides rightward along with it. That’s why the attachment thumbnails and other icons end up shifting too.
To fix this cleanly, we should change the DictateButton’s internal layout so the button stays anchored on the left while the transcript expands to its right. One simple way is to wrap the button in its own flex container and let the transcript take the remaining space:
```jsx
<DictateButton>
<button>🎤</button>
<div className="transcript-wrapper">
{transcript}
</div>
</DictateButton>
```
With `transcript-wrapper` set to `flex: 1` and `overflow-wrap: break-word`, the transcript will grow and wrap without pushing the button or the screenshots that live after it in the parent flex row.
For truncation, we can remove any hard max-width or ellipsis on the transcript text so it shows the full content when it wraps. If the transcript becomes very long, we can add a reasonable max-height with `overflow-y: auto` so it doesn’t push the send button off-screen, but the user can still scroll to see everything.
This keeps the mic button fixed on the left, keeps the screenshot thumbnails in place, and gives the user the full transcript they want. I’ll implement that change right away.
