## Instructions

1. Create an internal integration in [Notion integrations](https://www.notion.so/my-integrations).
2. Enable **Read content** and **Insert content**.
3. Use **Connections** on each Notion page or database to share it with the integration.
4. Enter its internal integration secret below.

The connection can only access shared content.

## Create Page

**Component key:** `notion.createPage`

Create a page under a shared Notion page or data source.

### Configuration

- **Parent Type** and **Parent ID**: Select the parent and enter its ID.
- **Title**: Enter the page title. The maximum length is 2,000 characters.
- **Properties**: For a data source, enter an optional JSON object that matches its property schema.
- **Children**: Enter an optional JSON array in the [Notion block format](https://developers.notion.com/reference/block).

For database entries, copy the data source ID from **Manage data sources** in Notion. Do not use the database ID.
Set the title through **Title**, including for data sources with a custom title property name.

Properties and Children accept JSON or expressions, such as &lbrace;&lbrace; previous().data.children &rbrace;&rbrace;.
Requests can contain at most 100 top-level blocks and 500 KB of JSON.

### Permissions and output

Enable **Insert content** and share the parent with the connection. Data source entries also require **Read content**.
The output contains the native page in data, including its id and url.

Creation does not retry automatically. After a network or server error, check Notion before you retry to avoid duplicate pages.

## Search

**Component key:** `notion.search`

Search shared page and data source titles. Search does not match page content or query data source entries.

### Configuration

- **Query**: Enter title text, or leave empty to list shared objects.
- **Object Type**: Select pages, data sources, or both.
- **Page Size**: Return 1–100 results. The default is 100.
- **Start Cursor**: Use next_cursor from the previous output. Keep the query and filters unchanged.
- **Sort Direction**: Optionally sort by the last edit time.

### Output

Each execution returns one page of results in data, with results, has_more, and next_cursor. Empty results are successful.

The connection requires **Read content**. Newly shared or created content may take time to appear. Requests do not retry automatically.
